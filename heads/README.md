# heads/

Raw 64x64 skin textures used as custom `PLAYER_HEAD` items in TargonCore (not part of the actual
resource pack — nothing under `assets/` references these; they're just hosted here via
`raw.githubusercontent.com` since that's already this project's stable public asset host).

- `discord-button-skin.png` — the Discord-logo-styled head for `/discord`'s clickable button item.
  Source skin: https://namemc.com/skin/4d91448b3fb8df1e (self-hosted here instead of linking
  NameMC's CDN directly — it 403s requests without browser-like headers, which a Minecraft client
  fetching the texture would trip).
